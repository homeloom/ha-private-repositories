# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue, discussion or pull request for a
vulnerability.

Report it privately with
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability):
open the **Security** tab of the repository and select
**Report a vulnerability**.

Include what you found, how to reproduce it and the versions affected. Leave
out personal data such as addresses, tokens or logs that identify a home.

You will get an answer within seven days. Once a fix is released, the
advisory is published and credits the reporter unless they ask otherwise.
